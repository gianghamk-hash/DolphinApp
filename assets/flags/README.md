# Country flag artwork

Source: https://github.com/lipis/flag-icons
Revision: ac7e0eb3259eb62aa6100c435607e2fe03896a97
License: MIT (included as LICENSE).
Only ISO country/territory 4:3 SVG assets are included. Names are generated with Node Intl.DisplayNames (vi/en); common guest-list aliases are added in dolphin-country-data.js.

Guest cards retain original nationality text. Known labels resolve locally; unresolved nationality-field labels alone may be sent to the authenticated Gemini callable. No personal name, agent, nationality inference from food or external image search is used. Uncertain labels show a small question mark; no flag is guessed. Images are fixed local allowlisted paths, rendered at 18×14 CSS pixels.
